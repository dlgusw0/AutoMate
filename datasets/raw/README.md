# AutoMate 학습 원본 이미지 수집

모든 이미지는 현재 `차량 샘플.jpg`와 비슷한 **전면 사선 각도**를 사용한다.
이미지는 JPG, JPEG, PNG 중 하나로 저장한다.

## 폴더별 목표

- `normal/`: 정상 차량 20장 이상
- `wheel_missing/`: 휘 누락 차량 20장 이상
- `headlight_missing/`: 헤드라이트 누락 차량 20장 이상
- `door_misaligned/`: 도어 단차·틀어짐 차량 20장 이상
- `unknown/`: 어둡거나 흐리고 가려진 이미지 10장 이상

## 변화를 줄 항목

- 차량 색상
- 공장 배경
- 조명 밝기
- 카메라 거리의 작은 변화
- 결함의 좌·우 위치

## 피할 이미지

- 똑같은 이미지의 단순 복사본
- 일러스트, 사진, 3D 렌더가 한 데이터셋에 무작위로 뒤섞인 구성
- 차량이 너무 작게 보이는 이미지
- 결함 부위가 화면 밖에 있는 이미지
- 로고, 문자, 워터마크가 결함 부위를 가린 이미지

`unknown/` 이미지는 YOLO 부품 학습에 바로 넣지 않고 OpenCV 품질 검사용으로 사용한다.
